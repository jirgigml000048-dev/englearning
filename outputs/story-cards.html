移动端是第二个项目

内容功能在浏览器里完美，APK 装到真机后另一批坑接连冒出：

⑧ 朗读全文没声音
Android WebView 不支持 Web Speech → 改顺序播 mp3
⑨ 构建 exit 127
gradlew 丢了执行位 → chmod +x + set -e
⑩ 给不了麦克风权限
manifest 缺 RECORD_AUDIO → 系统里没该项可选
英语训练师5 / 7

给孩子做 App 的教训

01
反馈密度 = 留存
每 5–10 秒必有正反馈，跟游戏抢的是注意力
02
绝不显示"错"
所有失败包装成"再试一次"，红叉 = 关 App
03
兴趣驱动 > 教学严谨
完美教材但孩子不开 = 0 学习
04
门槛要松
跟读 30% 就过，目的是让他开口，不是读对
05
诚实审计自己
用户问"X 是 Y 吗"立刻承认局限，别狡辩
